Get Pokémon Chest

One page. Three paths. Pick the first one that works for you.

1 Easiest — download the Mac installer (DMG)

This is the finished app. No coding.

Download DMG Download source zip Open Releases page

  1. Click Download DMG.
  2. Open the file → drag Pokémon Chest into Applications.
  3. First launch: right-click the app → Open (macOS Gatekeeper). Confirm Open.
  4. Done. Your collection loads from this folder / your PriceCharting export.

If the button 404s, use the Releases page link above, or Path 2 / Path 3 below.

2 Run in browser (no DMG build)

From the project folder on your Mac:

  1. Double-click start.command
  2. Allow it if macOS asks (right-click → Open the first time)
  3. Browser opens at http://localhost:8787
  4. Keep the Terminal window open while you use the app
# same thing from Terminal:
cd "/path/to/pokemon-chest"
./start.command

Scanner, PriceCharting live search, and iPhone phone-mode need this local server (or the .app).

3 Build a fresh DMG on your Mac

Only needed if you changed code and want a new installer.

  1. Install once (if missing): 
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# also need Node from https://nodejs.org
  2. In the project folder, double-click build-app.command 
    ./build-app.command
  3. When it finishes, Finder opens the DMG folder: 
    src-tauri/target/release/bundle/dmg/*.dmg

First build can take several minutes while Rust compiles.

What each file is

  • Pokemon.Chest_*.dmg — Mac installer
  • PokemonChest-source-*.zip — full source for that build
  • start.command — run in browser
  • build-app.command — make a new DMG on your Mac
  • GET-POKEMON-CHEST.html — this guide

Quick test checklist

  1. Stop any old server (close the Terminal, or Ctrl+C)
  2. Start again with start.command
  3. Hard-refresh the browser (Cmd+Shift+R)
  4. Open the 📷 Scanner tab

When you ask me to test, I should restart the local server and reopen the browser every time — not reuse a stale tab.
