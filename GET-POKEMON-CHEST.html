Get Pokémon Chest

Download the app, then unlock macOS Gatekeeper once. That “Not Opened / Done” dialog is normal for our GitHub builds until Apple notarization is wired.

If you see “Pokemon Chest” Not Opened

Apple could not verify “Pokemon Chest”…  →  button only says Done.
That is Gatekeeper. The DMG is safe for you; it is just not Apple-notarized yet (needs a paid Developer ID in CI).

Fix A — Settings (works on newest macOS):

  1. Click Done on that dialog.
  2. Apple menu  → System Settings → Privacy & Security.
  3. Scroll to the Security section (lower half of the page).
  4. Find: “Pokemon Chest” was blocked from use because it is not from an identified developer.
  5. Click Open Anyway.
  6. Enter your Mac password or Touch ID → click Open.

Fix B — one Terminal command (after the app is in Applications):

xattr -cr "/Applications/Pokemon Chest.app"
open "/Applications/Pokemon Chest.app"

Fix C — helper script (in the source zip / project folder):

  1. Double-click OPEN-ANYWAY.command (first time: right-click → Open).
  2. It clears quarantine and launches the app.

You only need this once per Mac. After Open Anyway, normal double-clicks work.

1 Download the Mac installer (DMG)

Download DMG Download source zip Open Releases page

  1. Open the DMG → drag Pokemon Chest into Applications.
  2. Eject the DMG.
  3. Open from Applications — if blocked, use the Gatekeeper fix above.

2 Skip the DMG — run in browser

No Gatekeeper fight. From the project / source zip folder:

  1. Double-click start.command (first time: right-click → Open).
  2. Browser opens http://localhost:8787.
  3. Keep the Terminal window open while you use it.
cd "/path/to/pokemon-chest"
./start.command

3 Build a DMG on your own Mac

Uses your Apple Development signing when available (often opens cleaner than the GitHub ad-hoc build).

  1. Install Rust + Node once if needed.
  2. Double-click build-app.command.
  3. Install from src-tauri/target/release/bundle/dmg/.
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# Node: https://nodejs.org
./build-app.command

Still may need Open Anyway once unless you notarize with a Developer ID.

Why this keeps happening

  • GitHub CI signs the app ad-hoc (no Apple notarization ticket).
  • Safari/Chrome mark downloads with a quarantine flag.
  • macOS Sequoia shows “Not Opened” with only Done — the allow button moved to Privacy & Security.

Permanent product fix later = Apple Developer ID + notarize in CI. Until then: Open Anyway once, or use start.command.
